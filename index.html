    Petunjuk Penggunaan

    Mulai cepat

    Buat bentuk, pilih transformasi, lalu lihat hasilnya.

    1. Pilih bentuk cepat atau tambahkan titik manual.
    2. Pilih refleksi, rotasi, dilatasi, atau translasi.
    3. Tekan “Terapkan Transformasi”.

    Interaksi dengan Canvas

    • Klik / Ketuk: Menambah titik pada koordinat bulat terdekat
    • Seret titik: Memindahkan titik asli; bayangannya ikut bergerak. Pusat rotasi/dilatasi juga bisa diseret. Ketuk P1 untuk menutup poligon
    • Seret (klik kiri atau kanan): Menggeser tampilan koordinat (pan)
    • Scroll Mouse: Memperbesar/memperkecil tampilan (zoom)
    • Pinch (Mobile): Gunakan dua jari untuk zoom
    • Drag (Mobile): Gunakan satu jari untuk menggeser
    • Keyboard: Fokuskan kanvas, lalu gunakan tombol panah untuk menggeser, + / - untuk zoom, dan 0 untuk reset

    Menambahkan Titik

    • Klik kanvas, atau gunakan input manual di panel visualisasi
    • Format yang diterima:
    (3, 5) 2, -4 A(1,2) x=3 y=5 2 -4 5; -2 (1,5; -2)

    Membuat Poligon

    1. Tambahkan minimal 3 titik dengan klik kanvas atau input manual
    2. Titik akan otomatis terhubung dengan garis sesuai urutan
    3. Klik "Tutup Poligon" untuk menghubungkan titik pertama dan terakhir
    4. Setelah menerapkan transformasi, "Lanjutkan dari Hasil" menjadikan bayangan sebagai bentuk berikutnya (komposisi transformasi, mis. refleksi lalu rotasi)

    Transformasi yang Tersedia

    • Refleksi: Pencerminan terhadap sumbu X, Y, garis y = ±x, x = h, y = k, atau garis kustom. Garis cermin ditampilkan putus-putus di kanvas
    • Rotasi: Perputaran dengan sudut (positif = berlawanan arah jarum jam) dan pusat yang dapat disesuaikan
    • Dilatasi: Penskalaan dengan faktor k (boleh negatif, tidak boleh 0) dan pusat dilatasi
    • Translasi: Pergeseran dengan vektor translasi

    Legenda Warna

    Biru: Bentuk asli (sebelum transformasi)
    Oranye: Hasil transformasi

    Tips

    • Gunakan tombol Segitiga, Persegi, atau Segilima di kartu "Buat Bentuk" untuk mulai dengan cepat
    • Koordinat ditampilkan dalam tabel untuk memudahkan analisis
    • Tombol +, −, dan ⌖ di pojok kanan bawah kanvas mengatur zoom dan mengembalikan tampilan awal
    • Kartu "Latihan" memberi soal acak; jawab koordinat bayangannya, lalu tekan "Lihat di kanvas" untuk memeriksa secara visual
    • Alamat halaman selalu menyimpan bentuk, parameter, dan langkah komposisi. "Salin Tautan Bentuk Ini" menyalinnya untuk dibagikan, misalnya sebagai soal dari guru
    • Koordinat ditampilkan hingga 2 angka desimal
